A production-ready repository focusing on practical computer vision, AI landmark tracking, and real-time interactive automation following strict **SOLID design principles** and clean OOP architecture.

| :--- | :--- | :--- | :--- |

---

## 🛠️ Tech Stack & Prerequisites

- **Python 3.10 – 3.13**
- **OpenCV (`cv2`)**: Video stream ingestion and graphic rendering
- **MediaPipe Tasks API**: 21 3D hand landmark inference
- **PyAutoGUI**: Real-time OS mouse pointer actuation
- **NumPy**: Vector math and coordinate interpolation

---

## 🚀 Quick Setup

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd python-ai-vision
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run Project 01 (Virtual Mouse):**
   ```bash
   cd 01-virtual-mouse
   python main.py
   ```

See the [01-virtual-mouse/RUN_GUIDE.md](./01-virtual-mouse/RUN_GUIDE.md) for detailed gesture instructions.
